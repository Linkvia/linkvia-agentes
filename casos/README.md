## Formas de cobrar un agente de consumo

| Forma | Cómo funciona | Ejemplo |
|---|---|---|
| Suscripción mensual | El usuario paga una cuota con Mercado Pago y el agente habilita el servicio | Práctica de inglés a $4.000 por mes |
| Gratis con versión paga | Lo básico gratis; recordatorios extra, reportes o audio, pagos | Gastos: registrar gratis, resumen mensual pago |
| Packs de uso | Se compran 30 consultas o 3 meses de una vez | CV: el primero gratis, pack de 5 cartas de presentación |
| Comisión por recomendar | El agente recomienda un servicio y el proveedor te paga | Vencimientos: "tu seguro vence, acá hay 3 cotizaciones" |
| Venta a empresas | La empresa paga para que sus empleados o socios lo usen | Inglés o hábitos para el personal de una pyme |
| Publicidad de un negocio | El agente es gratis y un negocio paga por aparecer, con el mensaje marcado como **Publicidad** y como máximo 1 por semana | Lista de compras gratis con las ofertas del súper del barrio |

Para cobrar, el agente manda un link de Mercado Pago de tu cuenta y se entera del pago. Está explicado en [cobrar con Mercado Pago](../docs/cobrar-con-mercado-pago.md).

**Cuánto le pagás a Linkvia.** Un agente de consumo se usa todos los días, así que conviene el plan **Creador**: 0,08 USD por persona activa al mes, con un mínimo de 15 USD. Con 1.000 suscriptores a $2.000 por mes, pagás unos 80 USD. Mientras el plan no esté activo, se aplican los planes por conversación.

## Datos sensibles

La Ley 25.326 protege especialmente los datos de **salud, religión, opinión política, afiliación sindical, origen étnico y vida sexual**. En Linkvia:

- **Se permiten con recaudos** los agentes de salud (ciclo, medicación, turnos de consultorio), religión, política y sindicatos. El negocio declara el rubro, Linkvia pide el consentimiento expreso antes del primer mensaje, el agente pide lo mínimo, no diagnostica y la persona puede borrar sus datos cuando quiera. Además, quien arma la base de datos la tiene que inscribir ante la AAIP.
- **No se permiten:** citas y servicios sexuales, terapia o atención psicológica hecha por una IA, agentes para menores o con datos de un menor (por eso no hay caso "bebé recién nacido"), antecedentes penales, reconocimiento de caras, seguir la ubicación de otra persona, señales de inversión, apuestas sin licencia, medicamentos con receta, vapeadores y armas.

El detalle está en las reglas de contenido de Linkvia. Esto no reemplaza el consejo de un abogado.
